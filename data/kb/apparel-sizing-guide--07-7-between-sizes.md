Section: 7. Between sizes

## 7. Between sizes

| Garment | If between sizes |
|---|---|
| Tee | Size up for relaxed, stay for athletic |
| Tempest 3L Shell | Stay — it already has layering room |
| Drift Parka | Size **down** — runs half large |
| Kestrel Windshell | Size **up** — cut trim |
| Merino base layer | Size down, it should be close-fitting |
| Switchback Pant | Either, the stretch covers it |
| Granite Softshell Pant | Size up, no give in the waistband |

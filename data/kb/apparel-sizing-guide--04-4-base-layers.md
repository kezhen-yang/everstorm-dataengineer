## 4. Base layers

The Ridgeline Merino 200 Crew and Bottom are cut close by design — a base layer
works by sitting against your skin, and a loose one does not regulate
temperature properly.

| Size | Chest | Waist |
|---|---|---|
| XS | 33–35 | 27–29 |
| S | 35–38 | 29–31 |
| M | 38–41 | 31–34 |
| L | 41–44 | 34–37 |
| XL | 44–47 | 37–40 |
| XXL | 47–51 | 40–44 |

Do not size up on base layers for comfort. If it feels snug when you first pull
it on, that is correct. Merino relaxes slightly with body heat.

Section: 5. Return window exceptions

## 5. Return window exceptions

| Situation | Window |
|---|---|
| Standard purchase | 30 days from delivery |
| Purchased 1 Nov – 31 Dec | Extended to 31 January |
| Final Sale items | No return unless defective |
| Custom-embroidered items | No return unless defective |
| Defective item | 12 months — see `warranty-and-defect-claims.md` |

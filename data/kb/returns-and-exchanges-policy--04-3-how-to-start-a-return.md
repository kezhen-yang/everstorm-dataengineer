## 3. How to start a return

1. Visit **everstorm.example/returns** and enter your order number and email.
2. Select **Refund** or **Exchange**.
3. Print the prepaid label and pack the items securely. Multiple items from
   the same order can share one box.

If you no longer have a printer, request a QR code instead and the carrier will
print at drop-off.

## 5. Partial refunds

Where you return part of an order:

- Merchandise value of the returned items is refunded in full.
- Sales tax on those items is refunded proportionally.
- Shipping is **not** refunded if any part of the order is kept.
- If the remaining basket drops below the $75 free-shipping threshold, we do
  **not** retroactively charge shipping. The original terms stand.
- Discount codes are reapportioned across the kept items, which can mean the
  refund is slightly less than the sticker price of what you sent back.

That last point causes friction, so an example. You buy two $100 items with a
20% code and pay $160. You return one. The code applied $20 to each item, so
your refund is $80, not $100. The item you kept still cost you $80.

## 5. Lost codes

We can look up and resend any code from the email address it was issued to.
Balances are held against the code, not the account, so a code forwarded to
someone else can be spent by them — treat gift card codes like cash.

If a gift card code is used without your authorisation, email
billing@everstorm.example. We can see where and when it was spent, and we will
usually reissue the balance once, as a goodwill matter. We cannot do it
repeatedly.
